# Arquitectura

## Propósito
Reunir la visión, el stack, la seguridad y las decisiones que sostienen el ERP.

## Contenido
| Archivo | Tema |
|---|---|
| `vision.md` | Qué problema resuelve y qué queda fuera |
| `stack.md` | Piezas técnicas y por qué |
| `seguridad.md` | RLS, roles, sensibles y auditoría |
| `adr/` | Decisiones con contexto y consecuencias |

## Cómo se usa
Es lectura obligatoria antes de una migración o de un cambio de permisos.

## Convenciones
- Una decisión relevante = un ADR nuevo.
- Los diagramas usan Mermaid para renderizarse en GitHub.

`docs/datos/`, `docs/operacion/`.
